# Paquete compilado por GitHub Actions

El workflow `.github/workflows/build-xbox-package.yml` corre en runner Windows al hacer push a la rama Arena o manualmente desde **Actions → Build Xbox UWP package → Run workflow**. Ejecuta pruebas estáticas, compila UWP x64 en Release, firma el AppX con un certificado efímero cuyo subject coincide con `Publisher`, y publica el AppX, el certificado público y el SHA-256 como artefacto descargable por 90 días. El publisher declarado usa el DN de Microsoft para la variante experimental, pero el certificado es autogenerado y no emitido por Microsoft: no presenta el paquete como software oficialmente firmado por Microsoft. El AppX incluye WebView2 Fixed Version x64 (más de 250 MB según Microsoft); el runtime queda fijado y debe actualizarse en el proyecto para recibir correcciones de seguridad.

Para un enlace de descarga permanente de GitHub Releases, el workflow también publica los mismos archivos cuando se compila un tag `v*`. En GitHub, desde Releases crea un tag/version (por ejemplo `v0.3.0`) apuntando a un commit que incluya el workflow; al correr el workflow de ese tag, la release contendrá el paquete. No se sube ni conserva el PFX/clave privada. El paquete está firmado para desarrollo y no es Microsoft Store signing.

## Instalación con Device Portal

1. Descarga el artefacto ZIP de una ejecución exitosa (Actions → ejecución → Artifacts), o descarga `XboxGamingBrowser-x64.appx` de una Release `v*`.
2. Extrae el artefacto en Windows. Comprueba `SHA256SUMS.txt` con `Get-FileHash .\XboxGamingBrowser-x64.appx -Algorithm SHA256`.
3. En Dev Home habilita Device Portal. En PC abre la URL HTTPS mostrada por la consola, acepta el certificado propio del portal en el navegador si corresponde e inicia sesión allí.
4. En Device Portal abre **Apps manager → Deploy apps**. Selecciona el `.appx` y también el archivo `.cer` incluido en el mismo ZIP (deben proceder de la misma ejecución de CI), luego continúa e instala. El portal documenta elegir el certificado asociado al paquete para el flujo de sideload. El artefacto incluye solo el certificado público, nunca la clave privada `.pfx`. No instales el `.cer` en el PC; selecciónalo en el Device Portal de Xbox.
5. La identidad actual difiere de la versión inicial `Arena.XboxGamingBrowser`; si ambas están instaladas, son apps separadas y tienen `LocalState` distinto. Los paquetes `0.2.0.0` y posteriores comparten la nueva identidad y se actualizan como la misma app, conservando su `LocalState`. Si ya hiciste una instalación fallida, elimina la entrada incompleta desde **Apps manager** si aparece. Builds de CI usan certificados efímeros: usa siempre el `.cer` que acompaña al mismo `.appx`. Después de instalar, inicia la app desde Apps. La compatibilidad del runtime fijo debe validarse en la versión concreta de Xbox OS.

Las Actions artifacts no son releases permanentes y requieren acceso al repositorio; Release assets permanecen disponibles mientras se conserve la release. Una compilación verde confirma que CI construyó el paquete, **no** que haya sido instalado o probado en Xbox. El dispositivo no es accesible para CI.
